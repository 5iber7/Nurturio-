# Assets and licenses

- 3D models: 16 original glTF/GLB assets in `apps/mobile/assets/models`, generated by `scripts/build-3d-models.mjs`. Includes the village, four worlds, farmer guide, animated honeybees/chickens, eight mature plants, two earlier growth stages and Buzz. No purchased or downloaded character art. Models use linear-space PBR material colors and shared geometry; total bundled model size is approximately 1.2 MB. The manifest identifies version 1 and original ownership.
- Rendering: `model_viewer_plus` 1.10.0 (Apache-2.0) bundles Google's model-viewer renderer. Flutter hosts WebGL in browser platform views and native WebViews. Lighting, shadows and camera orbit/zoom add depth. AR is disabled. The native asset server is local; Android allows cleartext only for localhost/127.0.0.1.
- World illustrations: original procedural Dart drawings in `world_art.dart`, retained for lighter graphics and unsupported platforms/headless tests. Plant painter retains exact growth progress in the fallback.
- Scene animations: original glTF node animations; reduced motion disables autoplay. Flame retains the pouring/rhythm mechanics.
- Interaction/ambience WAV files: original synthesized sounds generated by `scripts/create-audio.py`; no external samples. Music is optional and disabled by default.
- Nunito: Google Fonts distribution, SIL Open Font License. License is bundled at `assets/fonts/OFL.txt`.
- Icons: Flutter Material icons, the original plant notification vector and original Nurturio sprout launcher icons generated by `scripts/create-icons.py`. Store artwork still needs owner review.
- SQLite WASM: sqlite3.dart release artifact version 3.5.2; source/build licenses are supplied by that dependency. Original download: https://github.com/simolus3/sqlite3.dart/releases/tag/sqlite3-3.5.2.

Validate generated models with the pinned Khronos glTF Validator using `npm ci && npm run validate:models`. Keep geometry within mobile budgets and preserve accessible descriptions, lighter graphics, reduced motion and all offline mechanics. These models are stylized; expert biological review, physical-device GPU checks and store artwork review remain separate production tasks. Do not invent licenses for replacement art.
