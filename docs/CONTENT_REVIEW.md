# Content review

The initial packs cover 32 short lessons and eight plant profiles. Claims have a source registry, access dates and explicit expert-review status. They intentionally avoid unsupported exact lifespans, durations, crop yields, feed quantities and machine settings.

Before public release, an appropriate reviewer should verify bee biology/harvest, poultry welfare, food processing and plant guidance against current local sources. Some Penn State URLs could only be retrieved through search snippets during preparation; bee-specific curriculum especially needs manual verification. General vegetable sources are a starting point, not cultivar-specific validation.

Keep technical machinery, live beekeeping, veterinary care and hazardous treatments framed as supervised real-world activities. The game does not establish food safety or certify practical competence. Companion planting claims have not been added.

Real-life timing is currently qualitative. Add regional, variety-specific ranges only after documenting supporting source claims. Game-duration values are explicitly simulation settings. Expand the eight plant profiles into deeper cultivar lessons as content matures.

Source IDs and URLs are bundled in `assets/content/sources.json`. Curated online Buzz context is generated from the packs. Rebuild that context after any curriculum change; do not let model output modify approved learning content.
