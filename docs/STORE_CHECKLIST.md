# Store readiness checklist

- [ ] Confirm target ages, launch regions and store audience declarations.
- [ ] Verify current Apple review and Google Play Families rules.
- [ ] Finalize privacy policy, operator contact and Data Safety/privacy labels.
- [ ] Keep restricted Gemini integration disabled unless actual provider terms permit the audience.
- [ ] Complete a real consent solution before enabling child cloud/photos/AI.
- [ ] Review the original branded sprout launcher icons and final store artwork.
- [ ] Produce accurate store screenshots and age ratings.
- [ ] Verify camera/gallery denial, photo metadata handling and notifications on devices.
- [ ] Verify parent PIN recovery, secure storage, session limits and account deletion.
- [ ] Run iOS on a Mac/simulator and physical iPhone; test Android devices/emulator.
- [ ] Check large text, screen readers, reduced motion and offline restart.
- [ ] Commission appropriate factual review of agricultural/animal/food lessons.
- [ ] Configure release signing; debug signing is not a store release artifact.
- [ ] Run production Supabase ownership/authentication tests and retention jobs.

Reference policies: https://developer.apple.com/app-store/review/guidelines/ and https://support.google.com/googleplay/android-developer/answer/9893335. Review applicable child privacy obligations with current guidance, including https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions.
