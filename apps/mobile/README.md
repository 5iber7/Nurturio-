# Nurturio mobile

The Flutter/Flame application for iOS and Android. Four offline worlds teach honey production, olive oil, chicken care and gardening through 32 interactive quests.

Use Flutter 3.47.6. Run `flutter pub get` and `flutter run` from this directory. No cloud credentials are required for offline play. Validate with `flutter analyze` and `flutter test`; run the native quest journey with `flutter test integration_test/quest_flow_test.dart -d DEVICE_ID`.

See the repository's [setup guide](../../README.md), [build status](../../BUILD_STATUS.md) and [release blockers](../../docs/RELEASE_BLOCKERS.md) for backend configuration, demo mode, actual checks and remaining release work.
